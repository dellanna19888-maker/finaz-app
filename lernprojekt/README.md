# 🎓 Lernprojekt: Eine App – 4 Technologien

Willkommen zu deinem Lernprojekt! Hier baust du **immer dieselbe kleine App** –
eine **Aufgabenliste (To-Do-App)** – in vier verschiedenen Technologien.

Warum dieselbe App? Weil du so direkt vergleichen kannst, wie jede Technologie
dasselbe Problem löst. Das ist die schnellste Art, die Unterschiede wirklich zu
verstehen. 💡

---

## 📦 Die vier Projekte

| Ordner | Technologie | Installation nötig? | Was du lernst |
|--------|-------------|---------------------|----------------|
| `01-web-grundlagen` | HTML · CSS · JavaScript | ❌ Nein | Die Grundlagen des Webs: DOM, Events, Speichern im Browser |
| `02-vue` | Vue 3 + TypeScript | ✅ `npm install` | Modernes Framework, reaktive Daten, Komponenten |
| `03-react` | React + TypeScript | ✅ `npm install` | Das weltweit verbreitetste Framework, Hooks, State |
| `04-backend-node` | Node.js | ❌ Nein | Server, eine eigene API, Daten dauerhaft speichern |

---

## 🗺️ Empfohlene Reihenfolge

Arbeite die Projekte **von oben nach unten** durch – sie bauen didaktisch
aufeinander auf:

1. **`01-web-grundlagen`** – Fang hier an! Du brauchst nichts zu installieren.
   Hier verstehst du, was im Browser wirklich passiert. Alle Frameworks bauen
   auf diesen Grundlagen auf.

2. **`02-vue`** – Jetzt siehst du, wie ein Framework dir Arbeit abnimmt. Statt
   die Liste von Hand neu zu zeichnen, beschreibst du nur noch *wie es aussehen
   soll* – Vue kümmert sich um den Rest.

3. **`03-react`** – Dasselbe Prinzip, andere Schreibweise. Wenn du Vue und React
   nebeneinander siehst, verstehst du das gemeinsame Grundprinzip moderner
   Frameworks.

4. **`04-backend-node`** – Bisher lief alles nur im Browser. Jetzt baust du einen
   eigenen **Server**, der die Aufgaben dauerhaft speichert und über eine **API**
   bereitstellt. So funktionieren echte Web-Apps.

---

## ▶️ Schnellstart

In jedem Ordner findest du eine eigene `README.md` mit genauen Schritten.
Ganz kurz zusammengefasst:

```bash
# Projekt 1 – einfach die Datei im Browser öffnen:
#   lernprojekt/01-web-grundlagen/index.html  (Doppelklick genügt)

# Projekt 2 – Vue:
cd 02-vue
npm install
npm run dev

# Projekt 3 – React:
cd 03-react
npm install
npm run dev

# Projekt 4 – Node.js Server:
cd 04-backend-node
node server.js
# danach im Browser öffnen: http://localhost:3000
```

## 💡 Tipps fürs Lernen

- **Lies die Kommentare im Code.** Jede Datei ist ausführlich auf Deutsch
  kommentiert und erklärt Schritt für Schritt, was passiert.
- **Verändere etwas und schau, was passiert.** Ändere Farben, Texte, füge ein
  Feld hinzu. Kaputtmachen ist erlaubt – du lernst am meisten beim Ausprobieren.
- **Vergleiche die Projekte.** Öffne z.B. `app.js` (Projekt 1) und `App.vue`
  (Projekt 2) nebeneinander. Wie wird die Aufgabe jeweils zur Liste hinzugefügt?
- **Eine Idee zum Weitermachen:** Erweitere die Aufgabenliste später zu einem
  kleinen Ausgaben-Tracker (Betrag statt Text) – das passt thematisch perfekt
  zur großen `finaz-app` eine Ebene höher. 😉

Viel Spaß beim Lernen! 🚀
